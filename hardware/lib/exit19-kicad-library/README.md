# Exit19 KiCad Library

# About

This is a library for KiCad v6.x.x (and will not work for 5.x.x). 

Library contains:

* symbols,
* footprints,
* 3D models for footprints

used inside electronics department of Exit19.
It should be used as global library cloned to your local system and used with every Exit19 KiCad project.


# Rules

1. Always double check created symbols and footprints for potential errors. 

2. Always pull before making any changes, and push immediately after making a change to minimise the chance of conflicts.

3. Add 3D models' files with a `.stp` or `.step` extension.
